BOOTCAMP III - ETAPA FINAL TASKANALYZER
GUIA DE APLICACAO NO WINDOWS COM GIT BASH

IMPORTANTE
Este pacote contem arquivos completos do projeto. Copie o conteudo da pasta extraida para a raiz do seu repositorio local, mantendo as pastas e caminhos. Antes de sobrescrever arquivos, confirme que git status esta limpo e que nao ha alteracoes locais que precise guardar.

1. ABRIR O GIT BASH E ENTRAR NO REPOSITORIO

cd "$HOME/OneDrive/Área de Trabalho/sdd-task-analyzer"
git status
git fetch origin
git switch main
git pull origin main
git switch -c feature/etapa-final-devops

Se a ultima linha informar que a branch ja existe, use:
git switch feature/etapa-final-devops

2. COPIAR OS ARQUIVOS

Extraia o ZIP. Copie todos os arquivos e pastas de dentro da pasta Etapa_Final_TaskAnalyzer para a raiz de sdd-task-analyzer. Aceite substituir os arquivos quando solicitado. Nao copie a pasta externa como uma subpasta dentro do repositorio; Dockerfile, README.md e requirements.txt devem ficar diretamente na raiz.

3. VALIDAR PYTHON E OS TESTES

python --version
python -m venv .venv
source .venv/Scripts/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pytest -v

Resultado esperado: 8 passed. Se houver falha, nao avance para o commit; envie a mensagem completa do terminal para corrigirmos.

4. VALIDAR DOCKER

Abra o Docker Desktop e espere o mecanismo indicar que esta iniciado. Volte ao Git Bash, confirme que esta na raiz do projeto e execute:

docker --version
docker compose version
docker compose run --build --rm testes

O resultado esperado e a aprovacao de 8 testes. Se o Docker nao estiver instalado ou em execucao, essa etapa ainda nao foi validada.

5. CONFERIR E VERSIONAR

git status --short
git diff --check
git diff --stat

Confira o resultado. Nao adicione .venv, __pycache__ ou .pytest_cache.

Execute:
git add .
git diff --cached --stat
git commit -m "feat: adiciona CI Docker e governanca da etapa final"
git push -u origin feature/etapa-final-devops
